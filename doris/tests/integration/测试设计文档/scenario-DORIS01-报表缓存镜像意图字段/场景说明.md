# 场景 DORIS01：报表二期（v0.8）Doris 侧对齐缓存/镜像/意图字段

## 1. 场景说明

**被测对象**：`ai-gateway-observability/doris/sqls/` 下的真实 SQL 资产（不做副本，仅做与 `setup.sh` 一致的 `${VAR}` 变量替换）。

**背景**：v0.8 二期为 Doris 侧补齐缓存/镜像/意图三组字段（修改说明见 `doris/docs/modifications/2026-09-29-report-cache-mirror-intent-doris-alignment/design-changes.md`）：

- 明细表 `bfe_ai_request_log` +10 列（在线 ALTER / 全新安装 DDL 自带）
- Routine Load `COLUMNS(...)` 映射 +10 列
- 聚合表 `bfe_ai_metrics_1m` +3 个 KEY 维度（37→40 维，AGGREGATE KEY 重建）
- INSERT JOB `GROUP BY` +3 维（`COALESCE` 空值归一）

**测试环境**：本机 WSL2 单机 Doris 3.0.8（`environment/doris-installation.md`），Go 测试直连 `127.0.0.1:9030`，每个用例使用独立测试库（`bfe_observability_it_*`，结束后 `DROP DATABASE ... FORCE` 清理）。Doris 未启动时用例自动 `SKIP`。

**目录与运行**：

```bash
cd ai-gateway-observability/doris/tests/integration
go test ./... -v                                   # 全部
go test ./implementation/scenario-DORIS01-report-cache-mirror-intent/ -run TestTC01 -v   # 单例
```

## 3. 关键设计取舍

- **窗口确定性**：TC03 不创建周期 JOB（避免每分钟调度写入与手动执行竞争同一分钟桶），改为直接执行 JOB 文件中的 `INSERT..SELECT`，仅将 `WHERE log_time >= ...` 窗口替换为固定字面量（`GROUP BY` 及列映射保持原样），消除跨分钟边界 flaky。
- **demo 样例即 fixtures**：TC03 的期望值取自 `demo/normal_request.json`，测试同时校验 demo 文件与 DDL/口径的一致性。
- **集成测试驱动出的 Doris 3.0.8 兼容性修复**（详见修改说明 §4.4）：
  1. 既有 JOB 用 `ELEMENT_AT(ai_rate_limit_hits,1).rate_limit_policy_id` 访问 `ARRAY<STRUCT>` 元素字段，Doris 3.0.8 不支持任何 struct 字段解引用形式（`.`/`['field']`/CAST 均不可），导致 CREATE JOB 校验失败。修复：明细表新增 `rate_limit_policy_id`/`rate_limit_type`/`rate_limit_rule_name` 打平列，由 Routine Load 在导入时 `json_extract('$[0].xxx')` 提取（与 `level1Name` 同一模式），JOB 直接读标量列。
  2. 升级 ALTER 原设计用 `ADD COLUMN IF NOT EXISTS` 实现幂等，Doris 3.0.8 不支持该语法，改为普通 `ADD COLUMN`（每环境执行一次，重复执行报 `Duplicate column`，TC04 断言该预期行为）。
  3. 聚合表原子换名原设计写作 `SWAP WITH`，Doris 3.0.8 实际语法为 `ALTER TABLE a REPLACE WITH TABLE b PROPERTIES('swap'='true')`（TC05 用真实语法）。
- **幂等清理**：每个用例独立库名（含纳秒后缀），`t.Cleanup` 中 `DROP DATABASE ... FORCE`；`DORIS_IT_KEEP_DB=1` 可保留现场调试。
- **全局 JOB 名**：Doris INSERT JOB 名全局唯一（不按库隔离，HOWTO §5），创建前先 `DROP JOB WHERE JobName=...` 清理历史残留、用例结束再清理，避免"job name exist"与残留任务空转。
- **连接参数**：DSN 带 `multiStatements=true`，每条执行串以 `USE <db>;` 开头单连接执行，避免连接池 `USE` 漂移。
